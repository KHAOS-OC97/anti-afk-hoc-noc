## 📝 Como Executar

### Passo 1: Copie o Comando
Escolha um dos comandos acima baseado no tipo que quer.

### Passo 2: Abra seu Executor
- Synapse X
- Krnl
- Script-Ware
- Etc.

### Passo 3: Cole e Execute
1. Cole o comando na janela de código
2. Pressione **Execute** (ou Ctrl+Enter)

### Passo 4: Use a GUI
Uma GUI aparecerá no canto superior esquerdo.
Clique em **"ATIVAR"** para começar.

## 💡 Dicas

### Executar Automaticamente ao Entrar no Jogo

Se seu executor tem opção de "Startup Script" ou "Auto Execute":

1. Cole o comando acima
2. Marque a opção para auto-executar
3. O script rodará automaticamente quando entrar em um jogo

### Desabilitar Comando

Se quiser parar o script:
- Clique em **"DESATIVAR"** na GUI
- Ou deixe o jogo e volte

---

## 🎮 Testando

### No Roblox Studio:

Se preferir testar no Studio antes:

1. Abra seu projeto
2. Vá em: **StarterPlayer** → **StarterCharacterScripts**
3. Insert → **LocalScript**
4. Cole o código do arquivo `anti_afk_parado.lua` ou `anti_afk.lua`
5. Pressione F5

## 🆘 Se Não Funcionar

### Verifique:
1. Você está em um jogo Roblox
2. O executor é compatível
3. Pressione F9 para ver erros no console
4. Verifique a internet (precisa baixar do GitHub)

### Erro Comum:
```
403 - Forbidden
```
**Solução:** GitHub pode bloquear temporariamente. Tente novamente em alguns minutos.
